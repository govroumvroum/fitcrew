# FitCrew

AI fitness coaching app for 4 friends.

## Features

- **AI Coach** — onboarding conversation to define personal goals, tone, and generate tailored programs
- **Program generation** — structured workout programs based on individual goals and preferences
- **Workout logging** — quick, frictionless set/rep/weight tracking
- **Progression tracking** — graphs, PR detection, volume stats
- **Screenshot ingestion** — import data from Apple Health, Zepp, and Mi Fitness screenshots
- **Competition** — consistency and PR leaderboards
